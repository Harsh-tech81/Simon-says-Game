
# Simon Says Game - Web Edition  

## 🎯 *Project Overview*  
A classic *Simon Says* memory game built with *HTML, CSS, and JavaScript*. Test your memory by repeating the sequence of colors and sounds that Simon generates. The game increases in difficulty as you progress!  
  

---

## 🚀 *Features*  
✅ *Interactive Gameplay* – Click the colored buttons in the correct sequence.  
✅ *Increasing Difficulty* – The sequence grows longer with each successful round.  
✅ *Score Tracking* – Keep track of your high score.  
✅ *Responsive Design* – Works on desktop and mobile devices.  

---

## 🛠 *Technologies Used*  
- *HTML5* (Structure)  
- *CSS3* (Styling & Animations)  
- *JavaScript* (Game Logic & Interactivity)  

---

## 🎮 *How to Play*  
1. Press *START* to begin the game.  
2. Simon will flash a sequence of colors.  
3. Repeat the sequence by clicking the buttons in the same order.  
4. If correct, the sequence gets longer.  
5. If wrong, the game ends—try to beat your high score!
